# Digital ArtZ – static website

A static, responsive multi-page site for Digital ArtZ (https://digitalartz.in), ready for GitHub Pages.

## Structure
```
index.html            Home
services.html         Services overview (+ 8 service pages)
products.html         Products overview (+ clinician.html, event-master.html)
branding.html, about.html, contact.html, 404.html
assets/css/main.css   All styles
assets/js/main.js     Mobile menu
assets/img/logo.svg   Logo / favicon
.nojekyll             Tells GitHub Pages to serve files as-is
```

## Deploy on GitHub Pages
1. Upload everything in this folder to the root of the branch (keep the `assets` folder).
2. Settings → Pages → Source: "Deploy from a branch" → choose the branch and `/ (root)`.
3. Wait a minute or two, then hard-refresh the site (Ctrl+Shift+R / Cmd+Shift+R).
